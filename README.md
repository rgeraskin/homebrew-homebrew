# rgeraskin/homebrew tap

This [Homebrew](https://brew.sh/) tap repository simplifies the installation of my various projects. To install any package from this repository, start by executing the following command:

```sh
brew tap rgeraskin/homebrew
```

After tapping the repository, proceed to install the package you need. Each formula/cask in this repository has documentation in it's own repos.

The packages available from this repository include:

- [emojiq](https://github.com/rgeraskin/emojiq)
- [godiffyaml](https://github.com/rgeraskin/godiffyaml)
- [kctouch](https://github.com/rgeraskin/kctouch)
- [awsssologin](https://github.com/rgeraskin/awsssologin)
- [wifi-cli](https://github.com/rgeraskin/wifi-cli)
- [dump-psql-roles-grants](https://github.com/rgeraskin/dump_psql_roles_grants)
